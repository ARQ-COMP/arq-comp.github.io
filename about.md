# About

**ARQ-COMP** is a community competition for tools that perform automated
reasoning about quantum circuits and programs, including simulation,
equivalence checking, and verification.

Its mission is to make progress in this young and fast-moving area
**measurable**, **comparable**, and **reproducible**. To that end, **ARQ-COMP**
aims to:

* **Establish common ground.** Agree on input and output formats and task
  definitions, so that tools from different communities can be run on the same
  problems and compared directly.
* **Build a shared benchmark library.** Collect openly licensed benchmarks from
  the formal-methods and quantum-computing communities, and from applications
  in physics, chemistry, and materials science. The library should cover
  realistic workloads as well as hard instances that push today’s tools beyond
  their limits.
* **Pose new challenging problems.** Identify reasoning tasks about quantum
  circuits and programs that current tools cannot yet handle, and introduce
  them to the community as open challenges for future tool development.
* **Provide an independent snapshot of the state of the art.** Evaluate tools
  on equal terms, with transparent rules and fully reproducible results, so
  that users can choose the right tool and researchers can see where the real
  bottlenecks lie.
* **Drive the development of robust tools.** Encourage push-button tools that
  work across whole benchmark families and can be used by non-experts.
* **Bring communities together.** Connect researchers in automated reasoning,
  quantum compilation, and quantum software with the scientists who need their
  tools, keeping the entry barrier low for new teams.

**ARQ-COMP** is a friendly competition. Its main outcome is not a winner but
a shared, growing infrastructure of benchmarks, formats, and results that the
whole community can build on.
